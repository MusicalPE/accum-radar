매집 레이더 처음 설정하기

1. 한국거래소 회원 가입
   - KRX Data Marketplace(data.krx.co.kr)에 가입합니다.
   - 네이버·카카오 간편 로그인 말고, 아이디와 비밀번호로 가입한 "한국거래소 계정"이 필요합니다.
     (프로그램이 이 아이디·비밀번호로 자동 로그인해서 자료를 받습니다.)

2. 저장소에 계정 넣기 (비밀번호는 저장소에 공개되지 않고 암호화되어 보관됩니다)
   - GitHub 저장소 화면 > Settings > Secrets and variables > Actions
   - New repository secret 을 두 번 눌러 아래처럼 넣습니다.
       이름 KRX_ID   값: 한국거래소 아이디
       이름 KRX_PW   값: 한국거래소 비밀번호

3. 결과 화면(GitHub Pages) 켜기
   - Settings > Pages
   - Source: Deploy from a branch
   - Branch: main, 폴더: /docs  > Save
   - 1~2분 뒤 https://(깃허브아이디).github.io/(저장소이름)/ 에서 화면이 열립니다.

4. 처음 한 번 자료 채우기
   - 저장소 화면 > Actions > "매일 매집 레이더 갱신" > Run workflow
   - days 칸에 500 을 넣고 실행합니다. (약 2년치, 1~2시간 걸릴 수 있음)
   - 끝나면 결과 화면에 후보 종목과 과거 검증 결과가 나옵니다.

5. 그다음부터는 자동
   - 평일 저녁 6시 47분쯤 자동으로 실행되어 새 자료를 받고 점수를 다시 계산합니다.
   - 실패하면 GitHub 가 메일로 알려 줍니다. 가장 흔한 원인은 한국거래소 비밀번호 변경입니다.

6. 텔레그램 알림 받기 (선택)
   ① 텔레그램에서 @BotFather 를 찾아 대화를 열고 /newbot 을 보냅니다.
      봇 이름과 아이디(끝이 bot 으로 끝나야 함)를 정하면 토큰(숫자:영문 섞인 긴 글자)을 줍니다.
   ② 방금 만든 봇과 대화를 열고 아무 말이나 한 번 보냅니다. (봇이 먼저 말을 걸 수 없어서 필요)
   ③ 내 대화방 번호(chat id) 알아내기
      - 웹 브라우저 주소창에 https://api.telegram.org/bot토큰/getUpdates 를 넣고 엽니다.
        (토큰 자리에 ①에서 받은 토큰을 그대로 붙임)
      - 나오는 글에서 "chat":{"id":숫자 부분의 숫자가 chat id 입니다.
   ④ 저장소 Settings > Secrets and variables > Actions 에 두 개 더 넣습니다.
       이름 TELEGRAM_TOKEN     값: ①의 토큰
       이름 TELEGRAM_CHAT_ID   값: ③의 숫자
   - 넣고 나면 다음 자동 갱신 때부터 상위 10종목과 새로 들어온 종목이 휴대폰으로 옵니다.
   - 넣지 않으면 알림만 빠지고 나머지는 그대로 돌아갑니다.

조건 바꾸기
   - 판단 기간(20·40·60일)과 점수 비중은 결과 화면에서 바로 바꿔 볼 수 있습니다.
   - 시가총액·거래대금 기준 등은 screener/analyze.py 위쪽의 숫자를 바꾸면 됩니다.

주의
   - 결과는 살펴볼 후보를 좁히는 용도이며 매수·매도 추천이 아닙니다.
   - 한국거래소가 해외 서버(GitHub)의 접속을 막는 경우가 생기면 자료 받기가 실패할 수 있습니다.
     그때는 내 컴퓨터에서 직접 실행하는 방식으로 바꿀 수 있습니다.
